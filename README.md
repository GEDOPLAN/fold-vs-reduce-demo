# fold vs reduce

Das Projekt beinhaltet Beispielcode um die Unterschiede der Stream-Operation reduce und dem Stream-Gatherer fold aufzuzeigen.

Weiteres im Blog-Beitrag auf https://gedoplan.de/javablog/.

## Ausführung

Das Projekt nutzt JEP 512 (Compact Source Files and Instance Main Methods).
Es lässt sich mit Java 25 einfach auf der Kommandozeile ausführen.

```shell
java Example.java
```
